# Sri Dharma Kshetra — Temple & Religious Trust Website

Responsive eight-page front-end website concept.

## Pages
1. `index.html` — Home
2. `home-2.html` — Home 2 (Dharmic trust and philanthropy)
3. `about.html` — About
4. `pooja-timings.html` — Darshan & Pooja Timings
5. `festivals-events.html` — Festivals & Events
6. `online-seva.html` — Online Seva & Prasad
7. `donations.html` — E-Hundi Donations
8. `contact.html` — Contact

## Features
- Responsive design from 300px to desktop.
- Mobile/tablet hamburger navigation and active page highlight.
- Dark/light theme toggle and RTL direction toggle.
- Pooja booking, seva enquiry, donation interest and contact demo forms.
- Shared CSS and JavaScript.

## Run
Open `index.html` in a browser. Internet is required for Google Fonts and remote Unsplash sample imagery.

## Launch requirements
This is a front-end demo. Replace the sample trust name, phone, email, address, timings, festival dates, charges, payment details and imagery with verified temple-approved content.

Forms do not create bookings, accept donations, process payments or issue receipts. Connect secure backend services, an authorised payment gateway, transaction verification, accounting and receipt generation before enabling online transactions. Display 80G/tax claims only where current legal eligibility is confirmed. Do not invent festival dates, darshan timings, donation totals, Annadanam quantities, certifications or impact figures. Add approved privacy, cancellation, refund, donation and booking terms. Use the trust's verified official identity and channels to help devotees avoid fraudulent payment links.

Live Darshan and countdown widgets are intentionally not represented as live because no verified stream or schedule source was provided.
